# 페이서 (Pacer) — 기능 명세 / 유저 스토리 v1

> 상위 문서: 페이서 서비스 기획서 v1
> 문서 성격: 기획서를 "누가 / 무엇을 / 어떻게"로 분해한 개발 착수용 명세
> 우선순위 표기: **P0**(MVP 필수) / **P1**(2차) / **P2**(추후)

---

## 1. 문서 개요

- 목적: 기획서의 기능을 유저 스토리와 수용 기준(AC)으로 분해하여 개발·검증 기준을 확정
- 사용법: 각 스토리의 AC가 곧 QA 체크리스트. 예외 케이스는 구현 시 반드시 처리
- 다음 단계: 이 문서 → 화면 정의서 → ERD → API 명세

---

## 2. 사용자 정의 (Actor)

| Actor | 설명 |
|-------|------|
| 비로그인 방문자 | 앱 최초 실행, 로그인 전 상태 (진입 화면만 접근 가능) |
| 무료 사용자 | 로그인 완료, 하루 기본 질문 20개 한도 |
| 구독 사용자 | 유료 구독, 한도 해제 + 프리미엄 기능 |
| 시스템(AI) | 질문 생성·꼬리질문·평가·합불 판정을 수행하는 LLM |

> 관리자/운영 도구는 본 문서 범위 외 (별도).

---

## 3. 유저 스토리 (에픽별)

### E1. 온보딩 & 인증

**US-1.1 소셜 로그인 (P0)**
> 방문자로서, 카카오/애플/구글로 로그인하여 서비스를 이용하고 싶다.

- AC:
  - [ ] 진입 시 로그인 없이는 면접 기능에 접근 불가 (소셜 로그인 필수)
  - [ ] 카카오·애플·구글 3종 버튼 제공
  - [ ] 로그인 성공 시 홈으로 이동, 실패 시 사유 안내
  - [ ] iOS: 애플 로그인 버튼 필수 노출 (심사 4.8)
- 예외:
  - 소셜 인증 취소/실패 → 진입 화면 유지 + 재시도 안내
  - 네트워크 오류 → 오류 토스트 + 재시도

**US-1.2 최초 가입 온보딩 (닉네임) (P0)**
> 신규 사용자로서, 앱에서 쓸 닉네임을 설정하고 싶다.

- AC:
  - [ ] 최초 로그인 시 닉네임 입력 단계 진입
  - [ ] 소셜에서 이름/닉네임을 받았으면 prefill, 없으면 빈칸
  - [ ] 애플 첫 로그인 시 받은 이름·이메일을 즉시 저장 (재취득 불가 대비)
  - [ ] 닉네임 미입력 시 다음 진행 불가 (필수)
- 예외:
  - 소셜 응답에 이름/이메일 없음 → 빈칸으로 진행, 이메일 nullable 저장
  - 닉네임 중복 정책(허용/비허용)은 정의 필요 → 기본 허용

**US-1.3 개인정보 수집 동의 (P0)**
> 사용자로서, 어떤 정보가 수집되고 AI에 전송되는지 알고 동의하고 싶다.

- AC:
  - [ ] 필수/선택 동의 항목 구분 표시
  - [ ] 입력 데이터가 AI 분석을 위해 LLM에 전송됨을 고지
  - [ ] 처리방침·이용약관 열람 링크 제공
- 예외:
  - 필수 동의 거부 → 가입 진행 불가 안내

### E2. 면접 준비 (입력 · 설정)

**US-2.1 공고 입력 (P0)**
> 사용자로서, 지원할 공고를 입력해 맞춤 면접을 받고 싶다.

- AC:
  - [ ] 텍스트 직접 붙여넣기 지원 (기본)
  - [ ] 직무 템플릿 선택 지원 (공고 없이)
  - [ ] (P1) URL 입력 시 JobPosting 파싱 시도, 실패하면 복붙으로 폴백
- 예외:
  - 공고 텍스트 비어있음 → 진행 불가 안내
  - URL 파싱 실패 → "자동 추출 실패, 직접 붙여넣어 주세요" + 텍스트 입력 전환

**US-2.1a 직무 카테고리 선택 (전 직군) (P0)**
> 사용자로서, 공고가 없어도 내 직무를 골라 바로 면접 연습을 시작하고 싶다.

- AC:
  - [ ] **대분류 → 세부 직무 2단계 선택** (개발 / 기획 / 디자인 / 마케팅 / 영업·세일즈 / 데이터·분석 / 경영지원 / 고객지원 / 기타)
  - [ ] 세부 직무 선택 시 해당 직무 기반 일반 질문 세트로 면접 시작
  - [ ] 공고 입력과 병행: 공고가 있으면 공고 우선, 없으면 직무 템플릿으로 진행
  - [ ] 인기/최근 사용 직무 빠른 선택 제공 (진입 마찰 최소화)
  - [ ] 선택한 직무는 평가 가중치(US-4.4)와 연동
- 예외:
  - 원하는 세부 직무가 목록에 없음 → "기타" 선택 + 직접 입력 허용
  - 직무 미선택 상태 → 다음 단계 진행 불가 안내

**US-2.2 지원자 정보 입력 (P0)**
> 사용자로서, 내 경력/자기소개를 입력해 나에 맞는 질문을 받고 싶다.

- AC:
  - [ ] 경력·자기소개 텍스트 입력 (권장)
  - [ ] 이력서 업로드는 **선택**, 스킵 가능
  - [ ] 미입력 시에도 공고 기반으로 정상 진행
- 예외:
  - 이력서 파일 형식 오류 → 안내 후 스킵 허용

**US-2.3 면접 설정 (P0)**
> 사용자로서, 면접 유형·난이도·질문 수·페르소나·언어를 골라 연습 조건을 맞추고 싶다.

- AC:
  - [ ] 면접 유형 선택: 일반/압박 (P0) · 인성/직무/임원 (P1)
  - [ ] 난이도 선택 (하/중/상)
  - [ ] 기본 질문 개수 선택 (3/5/10 등)
  - [ ] 실시간 피드백 on/off 토글
  - [ ] 점수 표시 on/off 토글
  - [ ] (P1) 면접관 페르소나 선택
  - [ ] (P1) 진행 언어 선택 (한국어/영어)
- 예외:
  - 무료 한도 초과 예상 시 시작 전 안내 (US-6.x 연계)

### E3. 면접 진행

**US-3.1 채팅 기반 면접 진행 (P0)**
> 사용자로서, 면접관 질문에 텍스트로 답하며 실전처럼 연습하고 싶다.

- AC:
  - [ ] 질문이 채팅 형태로 순차 제시
  - [ ] 사용자 답변 입력·전송
  - [ ] 진행률 표시 (예: 질문 2/5)
  - [ ] AI 응답 스트리밍 표시(타이핑 효과)
- 예외:
  - LLM 응답 지연/오류 → 로딩 후 재시도 버튼
  - 전송 중 네트워크 끊김 → 입력 내용 임시 보관, 복구

**US-3.2 꼬리질문 (P0)**
> 시스템으로서, 답변 내용에 따라 꼬리질문을 던져 깊이를 확인한다.

- AC:
  - [ ] 답변 기반 꼬리질문 생성
  - [ ] 사용자가 충분히 이해했다고 판단되면 꼬리질문 중단, 다음 기본 질문으로
  - [ ] 꼬리질문은 무료 한도에서 **카운트 제외**
- 예외:
  - 답변이 지나치게 짧거나 무의미 → 재답변 유도 또는 넘어감

**US-3.3 "모르겠습니다" 넘어가기 (P0)**
> 사용자로서, 모르는 질문에서 막히지 않고 넘어가고 싶다.

- AC:
  - [ ] "모르겠습니다" 선택 시 다음 질문으로 진행
  - [ ] 해당 질문은 평가에 반영(미응답으로 기록)
- 예외:
  - 모든 질문을 스킵 → 최종 평가에 반영, 낮은 점수 안내

**US-3.4 일시정지 & 이어하기 (P0)**
> 사용자로서, 면접을 중간에 멈췄다가 나중에 이어서 하고 싶다.

- AC:
  - [ ] 진행 중 일시정지 → 상태 서버 저장
  - [ ] 이후 재진입 시 중단 지점부터 이어하기
- 예외:
  - 앱 강제 종료 → 마지막 저장 지점부터 복구

### E4. 피드백 & 결과

**US-4.1 실시간 피드백 (P1)**
> 사용자로서, 답변마다 즉시 피드백을 받아 바로 교정하고 싶다.

- AC:
  - [ ] 실시간 피드백 on일 때 답변 직후 간단 피드백 제시
  - [ ] off(압박 등)일 때는 노출 안 함
- 예외:
  - 피드백 생성 실패 → 최종 리포트로 대체 안내

**US-4.2 최종 리포트 (P0)**
> 사용자로서, 면접이 끝나면 종합 결과를 받고 싶다.

- AC:
  - [ ] 100점 만점 종합 점수 (점수 표시 off면 숨김)
  - [ ] **점수 표시 off여도 합격/불합격 판정·항목별 피드백·모범답안은 정상 제공**
  - [ ] 합격/불합격 판정 + **판정 근거** 제시
  - [ ] 평가 항목별 점수: 논리·설득력 / 직무 적합성 / 답변 구조 / 키워드 / (모범답안)
  - [ ] 각 질문별 모범 답안(일반 모범답안) 제시
- 예외:
  - 스킵 과다/답변 부족 → 평가 신뢰도 낮음 안내

**US-4.3 리포트 공유·내보내기 (P1)**
> 사용자로서, 결과 리포트를 이미지/PDF로 저장·공유하고 싶다.

- AC:
  - [ ] 이미지 카드 또는 PDF 내보내기
  - [ ] 공유 시트 연동
- 예외:
  - 내보내기 실패 → 재시도 안내

**US-4.4 직무별 평가 가중치 (P0)**
> 시스템으로서, 지원 직무에 맞는 가중치로 답변을 평가해 공정하고 의미 있는 점수를 준다.

- AC:
  - [ ] 선택된 직무(대분류/세부)에 따라 평가 항목 **가중치 프리셋** 적용
    - 개발: 기술 깊이 · 문제 해결 과정 비중 ↑
    - 영업·마케팅: 설득력 · 커뮤니케이션 · 성과 수치 비중 ↑
    - 디자인: 의사결정 근거 · 포트폴리오 설명 비중 ↑
    - 기획: 논리 구조 · 우선순위 판단 비중 ↑
  - [ ] 가중치가 종합 점수·합불 판정에 실제 반영
  - [ ] 평가 프롬프트/루브릭에 가중치를 명시해 결과 일관성 확보
  - [ ] P0는 대분류 단위 프리셋, 세부 직무 미세 프리셋은 P1로 확장
  - [ ] (P1) 사용자가 강조 역량을 직접 조정
- 예외:
  - 프리셋 없는 직무 → 기본(균등) 가중치로 폴백
  - 직무 정보 부족(공고만/템플릿만) → 확보된 정보 범위에서 가중치 추정

**US-4.5 부적절 질문 대응 코칭 (P1)**
> 사용자로서, 실제 면접에서 받을 수 있는 불법·부당한 질문에 어떻게 대응할지 배우고 싶다.

- AC:
  - [ ] AI는 나이·결혼·임신·출산·가족관계·종교·출신지역·외모 등 **불법·차별 질문을 생성하지 않음** (차단)
  - [ ] 별도 코칭 콘텐츠로 "실제 면접에서 이런 질문을 받으면 이렇게 대응" 가이드 제공
  - [ ] 리포트/팁 영역에서 관련 코칭을 자연스럽게 노출 (차별화 포인트)
- 예외:
  - 사용자가 그런 질문 자체를 요청 → **대응법 코칭 관점으로만 전환**, 질문 자체는 생성하지 않음

### E5. 기록 & 성장

**US-5.1 면접 대화 전문 재열람 (P0)**
> 사용자로서, 지난 면접의 대화 전체를 다시 열어보고 싶다.

- AC:
  - [ ] 면접 목록에서 특정 면접 선택
  - [ ] 질문·내 답변·꼬리질문·피드백·최종 리포트를 대화 형태로 재현
  - [ ] 서버 저장 → 기기 교체·재설치에도 유지
- 예외:
  - 데이터 로드 실패 → 재시도 / 목록 복귀

**US-5.2 성장 추이 (P1)**
> 사용자로서, 반복 연습의 성장 흐름을 보고 싶다.

- AC:
  - [ ] 종합 점수 추이 라인 차트 (난이도·유형 태그 표기)
  - [ ] 항목별 추이/레이더 (약점 진단)
  - [ ] 총 면접 횟수·연속 연습일(스트릭)
- 예외:
  - 데이터 1건 이하 → 빈 상태 UI + 첫 면접 유도

### E6. 구독 & 사용량

**US-6.1 무료 한도 & 자정 리셋 (P0)**
> 무료 사용자로서, 하루 기본 질문 20개까지 무료로 쓰고 싶다.

- AC:
  - [ ] 기본 질문 사용량 카운트 (꼬리질문 제외)
  - [ ] 하루 20개 도달 시 추가 진행 제한 + 안내
  - [ ] 매일 자정(KST) 리셋
  - [ ] 잔여 한도 표시
- 예외:
  - **면접 진행 중 한도 소진** → "무료 한도를 모두 사용했어요" 문구 + **Pro 구독 구매 유도(페이월)** 노출
    - 구독 완료 시 → 해당 지점에서 즉시 이어서 진행
    - 미구독(닫기) 시 → 해당 지점에서 중단, 진행분은 저장(이어하기로 재개 가능)
    - 페이월은 US-6.2 구독 결제 플로우로 연결

**US-6.1a 페이월 (한도 소진 트리거) (P0)**
> 무료 사용자로서, 한도를 다 쓰면 자연스럽게 Pro 구매를 안내받는다.

- AC:
  - [ ] 한도 소진 시점(면접 시작 전 / 진행 중 모두)에 페이월 노출
  - [ ] Pro 혜택(한도 해제 등) 요약 + 구독 CTA
  - [ ] 닫기 시 무료 상태 유지, 진행분 보존
- 예외:
  - 결제 취소/실패 → 무료 상태로 복귀, 진행분 유지

**US-6.2 구독 결제 (P0)**
> 사용자로서, 구독하여 한도 없이 연습하고 싶다.

- AC:
  - [ ] 인앱 구독(IAP) 결제
  - [ ] 서버 영수증 검증 후 권한 부여

## 5. 공통 예외 · 상태 원칙

- **로딩**: LLM·네트워크 작업은 로딩 인디케이터 + 취소/재시도 경로 제공

- **오프라인**: 진행 중 입력은 임시 보관, 복구 우선
- **가드레일**: 불법·차별 질문 생성 차단 + 대응 코칭으로 전환(US-4.5), 부적절 입력 모더레이션

## 6. MVP 컷 참고 (P0 요약)

P0만 모으면 1차 출시 최소 범위가 나온다:
- 소셜 로그인 필수 + 닉네임/동의
- 공고(복붙)·**직무 카테고리 선택(전 직군)**·지원자 정보 입력
- 면접 설정(일반/압박, 난이도, 질문 수, 피드백/점수 토글)
- 채팅 면접 + 꼬리질문 + 스킵 + 일시정지/이어하기
- 최종 리포트(점수·합불·근거·모범답안) + **직무별 평가 가중치(대분류 프리셋)**
- 대화 전문 재열람
- 무료 한도(20개)·자정 리셋 + 한도 소진 페이월 + 구독 결제

→ URL 파싱, 실시간 피드백, 인성/직무/임원 유형, 페르소나, 언어 선택, 성장 추이,
   공유, 부적절 질문 대응 코칭(US-4.5), 세부 직무 미세 가중치는 **P1 이후**로 미뤄도 서비스가 성립.
   (단, 페이월·구독 결제·직무별 대분류 가중치는 핵심이라 P0로 포함)
