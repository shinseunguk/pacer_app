## 1. 화면 맵 (IA)

```
진입/스플래시 (S00)
└─ 로그인 (S01)
   └─ 온보딩: 닉네임 (S02) → 동의 (S03)
      └─ 홈/허브 (S10)
         ├─ 면접 준비: 입력 (S11) → 직무 선택 (S11a) → 지원자 정보 (S12) → 설정 (S13)
         │  └─ 면접 진행 (S20)
         │     ├─ (한도 소진) 페이월 (S50)
         │     └─ 최종 리포트 (S30) → 홈 복귀
         ├─ 히스토리 목록 (S40) → 대화 전문 재열람 (S41)
         ├─ 성장 추이 (S42)
         └─ 설정 (S60) → 구독 관리 (S61)
```

## 3. 화면별 상세

> 각 화면은 구성요소 / 주요 액션 / 상태(로딩·에러·빈·성공) / 연결 US로 정의.

### S00 스플래시/진입 (P0)
- 구성: 로고, 세션 체크
- 액션: 자동 분기 (인증됨→S10, 미인증→S01, 온보딩 미완료→S02)
- 상태: 로딩(세션 확인) / 에러(네트워크→재시도)
- US: —

### S00a 온보딩 인트로 (P0)
- 구성: 슬라이드 3장(아트워크 + 배지 + 제목 + 본문), 진행 막대, 건너뛰기
  1. `AI 면접 코치` — 면접, 혼자 뛰지 마세요
  2. `맞춤 질문 · 꼬리질문` — 공고 그대로, 진짜 면접처럼
  3. `정량 피드백 · 성장 추적` — 뛸수록 빨라지는 페이스
- 액션: 다음 / 건너뛰기 / 시작하기 → S01
- 상태: 본 적 있으면 표시하지 않는다(기기 단위, 로그아웃해도 유지)
- 근거: 소셜 로그인 앞에 가치를 설명하는 구간이 없으면 계정 요구 단계에서 이탈한다
- US: —

### S01 로그인 (P0)
- 구성: 로고, 카카오·애플·구글 버튼, 약관 링크
- 액션: 소셜 로그인
- 상태: 로딩(인증 중) / 에러(취소·실패→재시도 안내)
- 비고: iOS는 애플 버튼 필수 노출
- US: US-1.1

### S02 온보딩·닉네임 (P0)
- 구성: 닉네임 입력 필드(소셜값 prefill), 다음 버튼
- 액션: 닉네임 확정
- 상태: 유효성 에러(빈값) / 성공(다음)
- 비고: 애플 최초 이름·이메일은 진입 시점에 저장 완료
- US: US-1.2

### S03 온보딩·동의 (P0)
- 구성: 필수/선택 동의 항목, LLM 전송 고지, 약관·처리방침 링크
- 액션: 동의 후 시작
- 상태: 에러(필수 미동의→진행 불가)
- US: US-1.3

### S10 홈/허브 (P0)
- 구성: 인사(닉네임), **잔여 무료 한도**, "새 면접 시작" CTA, 최근 면접 요약, 성장추이/히스토리/설정 진입
- 액션: 면접 시작, 기록/성장/설정 이동
- 상태: 빈 상태(첫 사용자→첫 면접 유도) / 로딩(요약 fetch)
- US: US-5.x, US-6.1(잔여 한도)

### S11 면접 준비·입력 (P0)
- 구성: 입력 방식 탭(텍스트/URL/직무), 공고 텍스트 영역, 다음
- 액션: 공고 입력 또는 직무 선택 진입
- 상태: 에러(빈 공고, URL 파싱 실패→복붙 전환) / 로딩(URL 파싱)
- US: US-2.1

### S11a 직무 카테고리 선택 (P0)
- 구성: 대분류 리스트 → 세부 직무 리스트, 인기/최근 직무, "기타+직접입력"
- 액션: 세부 직무 선택
- 상태: 빈 상태(검색 결과 없음→기타) / 에러(미선택→진행 불가)
- US: US-2.1a

### S12 지원자 정보 입력 (P0)
- 구성: 경력/자기소개 입력, 이력서 업로드(선택·스킵)
- 액션: 입력/스킵 후 다음
- 상태: 에러(이력서 형식 오류→스킵 허용)
- US: US-2.2

### S13 면접 설정 (P0)
- 구성: 면접 유형(일반/압박, P1: 인성/직무/임원), 난이도, 질문 수, 실시간 피드백 토글, 점수 표시 토글, (P1) 페르소나·언어
- 액션: 설정 확정 → 면접 시작
- 상태: 경고(무료 한도 초과 예상 안내)
- US: US-2.3

### S20 면접 진행 (P0)
- 구성: 진행률(질문 n/N), 채팅(면접관 질문/내 답변/꼬리질문), 입력창, "모르겠습니다", 일시정지
- 액션: 답변 전송, 스킵, 일시정지/이어하기
- 상태: 로딩(AI 응답 스트리밍) / 에러(LLM 오류·네트워크→재시도, 입력 임시보관) / 한도 소진→S50
- US: US-3.1, 3.2, 3.3, 3.4, (US-4.1 실시간 피드백 인라인)

### S30 최종 리포트 (P0)
- 구성: 종합 점수(토글 시 숨김), 합격/불합격 + 근거, 항목별 점수, 질문별 모범답안, 공유/내보내기(P1)
- 액션: 공유, 홈 복귀, 히스토리 저장(자동)
- 상태: 로딩(평가 생성) / 경고(스킵 과다→신뢰도 낮음)
- US: US-4.2, 4.3, 4.4

### S40 히스토리 목록 (P0)
- 구성: 지난 면접 카드(직무·유형·점수·날짜)
- 액션: 항목 선택→S41
- 상태: 빈 상태(0건→첫 면접 유도) / 로딩·로드 실패
- US: US-5.1

### S41 대화 전문 재열람 (P0)
- 구성: 질문·답변·꼬리질문·피드백·리포트를 대화형으로 재현
- 액션: 스크롤 열람, 리포트 재확인
- 상태: 로딩 / 에러(로드 실패→목록 복귀)
- US: US-5.1

### S42 성장 추이 (P1)
- 구성: 종합 점수 추이 라인(난이도·유형 태그), 항목별 레이더/추이, 총 횟수·스트릭
- 액션: 기간·항목 필터
- 상태: 빈 상태(데이터 1건 이하→유도)
- US: US-5.2

### S50 페이월 (P0)
- 구성: "무료 한도 소진" 안내, Pro 혜택 요약, 구독 CTA, 닫기
- 액션: 구독 진행(→S61 결제), 닫기(무료 유지·진행분 보존)
- 상태: 로딩(결제) / 에러(결제 실패·취소→무료 복귀)
- US: US-6.1a, 6.2

### S60 설정 (P1)
- 구성: 계정 정보, 구독 관리 진입, 약관·처리방침, 로그아웃, 탈퇴
- 액션: 로그아웃, 탈퇴(→파기)
- 상태: 확인 모달(탈퇴·구독중 안내)
- US: US-7.1

### S61 구독 관리 (P0)
- 구성: 현재 구독 상태, 구매/복원(restore), 해지 안내
- 액션: 구독 결제, 복원
- 상태: 로딩(영수증 검증) / 에러(검증 실패→재시도)
- US: US-6.2

## 4. 공통 상태 · 컴포넌트 원칙

- **로딩**: LLM·네트워크 작업은 스켈레톤/인디케이터 + 취소·재시도 경로
- **에러**: 원인 + 다음 행동 제시 (막다른 화면 금지)
- **빈 상태**: 히스토리·성장추이 0건 시 첫 행동 유도 UI
- **오프라인**: 진행 중 입력 임시 보관, 복구 우선
- **글로벌 요소**: 상단 잔여 한도 뱃지(무료 사용자), 로딩/토스트 공통 컴포넌트
- **가드레일**: 불법·차별 질문 차단 + 대응 코칭(US-4.5)
